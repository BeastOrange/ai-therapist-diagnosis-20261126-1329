# Your AI Therapist's Diagnosis Entry

## Overview
This program deterministically writes an entry for the "Your AI Therapist's Diagnosis" competition by outputting a single-line joke to `/output/entry.txt`:

> "My clinical diagnosis is that you're not emotionally unavailable, you're just an expired free trial of a functional adult."

## How to Run
Run the program with:

```bash
python3 main.py
```

## Joke Criteria Targeted
- **Surprising turn**: It begins with a solemn clinical observation about emotional unavailability before subverting expectations by diagnosing the human with an expired software license.
- **Punchline at the end**: Delays the final comedic punch to the very last words ("functional adult"), maximizing comedic timing and contrast.
- **Tight one-liner**: At 122 characters, the joke delivers a sharp premise and unexpected twist in a single rapid sentence without filler.
- **Original**: Rather than generic robot tropes, it creates a fresh intersection between modern therapy culture and freemium software limitations.
